# riki-short-video-reference-breakdown



将参考视频、可访问链接或关键帧拆解为适用于 AIGC TVC/短视频制作的前期方案。



## 能力



- 参考视频与关键帧的视觉风格拆解
- 
- 色彩、影调、构图、镜头运动、剪辑节奏、转场、材质、声音和文字方式分析
- 
- 风格规范提炼
- 
- 原创镜头表与逐镜生成提示词
- 
- 跨镜头连续性锚点
- 
- AIGC 短视频验收清单
- 
- 区分观察、推断与无法确认的信息
- 
- 迁移参考片的视觉语法，不照搬原片主体、商标、文案、剧情或独特镜头组合
- 


## 使用



将本目录作为 Skill 使用，入口文件为 `SKILL.md`。默认中文交付；指定生成器后，可按目标生成器调整提示词格式。



模板位于 `templates/`：



- `style-guide-template.md`：参考视频风格规范
- 
- `shot-list-and-prompts-template.md`：镜头表与逐镜生成提示词
- 
- `qc-checklist-template.md`：AIGC 短视频验收清单
- 


本 Skill 只负责参考拆解、前期方案和提示词，不会在未获明确要求时自动生成视频、编写渲染代码或发布内容。



## 目录



- `SKILL.md`：核心工作流与质量标准
- 
- `templates/`：可复用交付模板
