# AIGC 短视频验收清单

先检查阻断性问题；未通过时先修复再做美化。根据项目删改不适用项。

## 方向与品牌
- [ ] 开场在目标时间内建立钩子，信息与 brief 一致。
- [ ] 产品外观、包装、功能描述、品牌色、Logo、CTA 与已提供素材一致；无凭空新增的事实或数据。
- [ ] 只迁移参考片的视觉语法，没有照搬其角色、商标、文案、故事或独特镜头组合。

## 风格与镜头
- [ ] 主色、对比度、光线、质感、构图和运镜符合风格规范。
- [ ] 镜头节奏与参考片/目标平台匹配；总时长准确，时间线无空档或超时。
- [ ] 每镜主体与产品外观连续；方向、视线、道具、场景和动作衔接合理。
- [ ] 每镜动作可读，没有多余肢体/物体、形变、闪烁、漂移或不必要的运动。

## 画面与可读性
- [ ] 主体和关键产品细节清晰，手机尺寸下仍可辨认。
- [ ] 文字、数字、Logo、UI 准确且不被裁切；优先核对后期合成版本。
- [ ] 重要信息避开平台界面遮挡区；裁切到目标画幅后主体仍完整。
- [ ] 无明显生成伪影、重复元素、跳帧、突变或不自然的首尾帧。

## 声音与交付（适用时）
- [ ] 音乐、旁白、环境声与情绪一致；音效/剪辑点同步且无突兀爆音。
- [ ] 时长、画幅、帧率、分辨率、编码和字幕格式符合交付要求。
- [ ] 已检查静音播放的可理解性，并检查有声播放的混音与响度。
